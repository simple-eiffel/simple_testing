Overview

simple_testing is a production-ready test framework that implements advanced testing patterns for Eiffel: three-tier fixture architecture, Design by Contract with formal verification, and exception-safe cleanup guarantees.

Built on top of standard EQA_TEST_SET, simple_testing adds the patterns and infrastructure needed for robust, maintainable test suites in large Eiffel systems.

Key Features

🏗️ Three-Tier Fixtures

System-level: Once per test run (database, server)
Feature-level: Once per test (isolation)
Nested/scoped: Callback context with LIFO cleanup

📝 Design by Contract

Full require/ensure/invariant support. Tests verify contracts with formal frame conditions (what did NOT change) using MML model queries.

⚡ Exception-Safe Cleanup

Cleanup is guaranteed even if test logic throws. Postconditions hold after exceptions. LIFO ordering respected.

🔄 SCOOP Compatible

Concurrency-ready with actor model semantics. Works with separate references and concurrent test execution.

🛡️ Void-Safe

void_safety="all" throughout. All code is void-safe. Eliminates null reference errors.

✔️ 40+ Assertions

Boolean, object, equality, numeric, string, collection, and advanced assertions. Epsilon support for floating-point.

Quick Example: Three-Tier Fixtures

Demonstrate system-level and feature-level fixture patterns:

-- System-level: Called once per test run
class DATABASE_TEST_SYSTEM
inherit TEST_SYSTEM
feature
    on_prepare_test_system do
        database.connect ("test_db")
        database.create_schema
    end
    on_clean_test_system do
        database.drop_schema
        database.close
    end
end

-- Feature-level: Called once per test
test_user_operations
    local l_fixture: DATABASE_FIXTURE
    do
        create l_fixture
        l_fixture.on_create  -- Begin transaction

        database.insert_user ("alice")
        assert ("user_created", database.user_exists ("alice"))

        l_fixture.on_destroy  -- Rollback transaction (always runs, even if exception)
        assert ("transaction_rolled_back", not database.user_exists ("alice"))
    end
