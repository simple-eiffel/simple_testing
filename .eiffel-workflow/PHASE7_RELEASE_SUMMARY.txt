## KEY FEATURES

✅ Design by Contract (DBC) Throughout
   - All classes have require/ensure/invariant
   - Contracts formalized with MML model queries
   - Tests verify contract satisfaction

✅ Three-Tier Fixture Architecture
   - System-level (singleton, once per test run)
   - Feature-level (isolation, once per test)
   - Nested/scoped (callbacks with LIFO cleanup)

✅ 40+ Assertion Methods
   - Boolean assertions
   - Object/reference assertions
   - Equality assertions
   - Integer/numeric assertions
   - String assertions
   - Collection assertions
   - NATURAL_64 assertions

✅ Mathematical Model Library (MML) Integration
   - Model queries for state specification
   - Frame conditions for what did NOT change
   - Formal verification of contracts

✅ SCOOP Compatibility
   - All classes work with separate references
   - Actor model semantics respected
   - Concurrency-ready implementation

✅ Void Safety
   - void_safety="all" in ECF
   - All code is void-safe
   - Detachable/attached type checking

✅ Exception-Safe Cleanup
   - Cleanup guaranteed even if operations throw
   - Postconditions hold after exceptions
   - Rescue clauses ensure invariants maintained
